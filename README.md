# Tower Duel — демо 1×1

Асимметричная PvP-дуэль: один игрок строит оборону, второй ведёт осаду.
Матч — **BO3**: три раунда, в каждом новый бюджет и новая попытка пробить базу.

Репозиторий содержит playable-демо (Godot 4.5), соло-режим против бота,
сетевую игру по ENet и полный геймдизайнерский аудит с внедрённым бэклогом:
[`docs/GDD_AUDIT_RU.md`](docs/GDD_AUDIT_RU.md).

## Запуск

1. Установите **Godot 4.5** (Forward+).
2. Откройте `project.godot` или запустите из консоли:

```bash
godot --path .
```

GodotSteam **не обязателен**: без него работают тренировка и игра по ENet,
недоступен только ранговый поиск через Steam.

## Режимы

| Режим | Как попасть | Что внутри |
|---|---|---|
| 🎓 Тренировка | главное меню → «ТРЕНИРОВКА · ПРОТИВ БОТА» | соло 1×1 с ИИ, MMR и статистика Steam не меняются |
| ⚔ Быстрый матч | «Игра с другом» → хост/подключение по ENet | честный PvP 1×1 |
| 🏆 Ранговый поиск | «В БОЙ · РАНГОВЫЙ ПОИСК» | Steam-лобби + MMR (нужен GodotSteam) |

## Правила матча

* **ПОДГОТОВКА 12 с** — защитник строит башни, штурмовик собирает очередь.
  Защитник видит состав очереди («РАЗВЕДКА») и предупреждение «⚠ ВОЗДУХ».
* **ШТУРМ 60 с** — юниты выходят волной; атакующий получает 1,5 кредита/с.
* **ИТОГ 8 с** — счёт раунда, затем следующий бюджет.
* База — **15 HP** на раунд. Победа в **2 раундах из 3**.
* Бюджеты: атакующий **200 / 320 / 480** (+капельные), защитник **240 / 100 / 100**.
* Награды: атакующему **+50 %** цены за прорыв, защитнику **+25 %** за убийство.
* Способности (по одной на раунд): **РЕМОНТ** (+2 HP) и **РАЗГОН**
  (×1,4 скорострельность на 4 с) — у защитника; **ПРОРЫВ** — у атакующего:
  мгновенно выпускает всю очередь одним залпом.
* Выход из матча = поражение (сдача фиксируется в статистике).

## Управление

* **Мышь** — выбор башни/юнита, постановка на карту, кнопки HUD.
* **Esc** — пауза и «Сдаться».
* В соло подсказки обучения появляются автоматически; их можно свернуть
  кнопкой «?».

## Деки

Перед матчем собираются **3 башни** и **3 юнита** (сохраняется в
`user://loadout.cfg`). В бою доступны только выбранные карты; башен одного
типа — не больше двух, всего — до восьми.

| Башня | Роль | Юнит | Роль |
|---|---|---|---|
| Снайпер | бронебойный, бьёт тяжёлых | Бегун | дешёвый поток |
| Мортира | AoE по земле | Наездник | плотная конница |
| Криостан | замедление | Танк | аура −25 % урона союзникам |
| Огнемёт | дешёвый AoE в упор | Змей | воздух, иммунен к замедлению |
| Тесла | **только воздух**, цепь | Босс | 800 HP, 6 урона базе |

Полная матрица урона, экономика и обоснование чисел — в
[`docs/GDD_AUDIT_RU.md`](docs/GDD_AUDIT_RU.md), раздел 2.3.4 и приложение H.

## Баланс-инструмент

`tools/balance_audit.py` — детерминированный симулятор (Python 3.10+, без
зависимостей). Повторяет `tower.gd` / `projectile.gd` / `game_state.gd`:
матрицу урона, приоритеты цели, ауру, сплеш, цепь, замедление, экономику.

```bash
python3 tools/balance_audit.py --profile v2 all      # геометрия, экономика, симуляция
python3 tools/balance_audit.py --profile v2 decks    # матрица «дека × состав атаки»
python3 tools/balance_audit.py --profile v1 all      # снимок аудита (для сверки)
```

Профиль `v2` — текущие числа из `scripts/game_db.gd` и
`autoload/game_state.gd`. После правки баланса **обязательно** прогнать
`decks`: он ловит «одну кнопку», которая забирает раунд у любой деки.

## Проверки

```bash
gdparse $(find scripts autoload tools -name '*.gd')      # синтаксис
gdlint  $(find scripts autoload tools -name '*.gd')      # стиль (gdtoolkit 4.5)
godot --headless --path . --script res://tools/check_project.gd
godot --headless --path . --script res://tools/smoke_test.gd   # 2 процесса
```

## Известные ограничения

* Баланс проверен симулятором, **но не живыми матчами** (в окружении сборки
  не было Godot CLI). Чеклист плейтеста — приложение G аудита.
* Арт — примитивы (полигоны, процедурные текстуры): это прототип, не финал.
* Ранговый поиск требует Steamworks-приложения и заполненного Partner Portal.
