# Tower Duel — демо 1×1

Асимметричная PvP-дуэль: один игрок строит оборону, второй ведёт осаду.
Матч — **BO3**: три раунда, в каждом новый бюджет и новая попытка пробить базу.

Репозиторий содержит playable-демо (Godot 4.5), соло-режим против бота,
сетевую игру по ENet и полный геймдизайнерский аудит с внедрённым бэклогом:
[`docs/GDD_AUDIT_RU.md`](docs/GDD_AUDIT_RU.md).

## Запуск

1. Установите **Godot 4.5** (Forward+).
2. Откройте `project.godot` или запустите из консоли:

```bash
godot --path .
```

GodotSteam **не обязателен**: без него работают тренировка и игра по ENet,
недоступен только ранговый поиск через Steam.

## Режимы

| Режим | Как попасть | Что внутри |
|---|---|---|
| 🎓 Тренировка | главное меню → «ТРЕНИРОВКА · ПРОТИВ БОТА» | соло 1×1 с ИИ, MMR и статистика Steam не меняются |
| ⚔ Быстрый матч | «Игра с другом» → хост/подключение по ENet | честный PvP 1×1 |
| 🏆 Ранговый поиск | «В БОЙ · РАНГОВЫЙ ПОИСК» | Steam-лобби + MMR (нужен GodotSteam) |

## Правила матча

* **ПОДГОТОВКА 10 с** — защитник ставит башни, штурмовик собирает очередь.
  Разведки состава больше нет: заход соперника не виден до первого юнита.
* **ШТУРМ** — **окно спавна 30 с**: штурмовик покупает и выпускает юнитов
  (кнопка «ДЕРЖАТЬ» — поток до 10 покупок в секунду). После 30-й секунды
  окно закрывается, и раунд идёт до последнего живого юнита — никакого
  таймера бездействия, только добивание. Предохранитель — 75 с.
* Перерыва между раундами нет: раунд закончился — сразу подготовка следующего.
  Победа в **2 раундах из 3**, база — **15 HP** на раунд.
* Бюджеты (накапливаются, неиспользованное золото переходит дальше):
  штурмовик **260 / 180 / 220** + **2 кр/с** капельно, защитник **280 / 160 / 200**.
* Награды: атакующему **+50 %** цены за прорыв, защитнику **+25 %** за убийство.
* Способности (по одной на раунд): **РЕМОНТ** (+2 HP) и **РАЗГОН**
  (×1,4 скорострельность на 4 с) — у защитника; **ПРОРЫВ** — у атакующего:
  мгновенно выпускает всю очередь одним залпом.
* Выход из матча = поражение (сдача фиксируется в статистике).

## Башни и юниты

Башен одного типа можно строить **сколько угодно** — ограничение только
кредиты и свободные клетки. Каждая башня и каждый тип юнитов качаются до
**10-го уровня**: клик по башне — апгрейд, кнопка «УР n → n+1» на карточке
юнита — прокачка типа (действует на все следующие покупки).

| Башня | Цена | Роль |
|---|---:|---|
| Снайпер | 70 | бронебойный хитскан, ×1,5 по тяжёлым, ×0,75 по воздуху |
| Мортира | 105 | AoE по земле, воздух не задевает |
| Криостан | 70 | замедление −50 % на 2 с |
| Огнемёт | 75 | дешёвый AoE в упор (120 px) |
| Тесла | 120 | **только воздух**, цепь на 2 цели |

| Юнит | Цена | HP | Скорость | Урон базе |
|---|---:|---:|---:|---:|
| Бегун | 15 | 48 | 150 | 1 |
| Наездник | 30 | 108 | 125 | 2 |
| Танк | 50 | 270 | 55 | 3 (аура −25 % союзникам) |
| Змей | 30 | 108 | 115 | 1 (воздух, игнорирует замедление) |
| Босс | 165 | 960 | 46 | 6 |

Апгрейд башни: +22 % урона, +3 % скорострельности и +2,5 % радиуса за
уровень (на 10-м — ×3,78 DPS). Апгрейд юнита: +10 % HP и +1,5 % скорости за
уровень, **+1 урон базе только на 10-м**; полная прокачка типа стоит около
десяти юнитов этого типа.

## Управление

* **Мышь** — выбор башни/юнита, постановка на карту, кнопки HUD.
* **Клик по башне** — купить следующий уровень (в любой фазе).
* **«ДЕРЖАТЬ»** на карточке юнита — клик покупает одного, удержание льёт
  поток, пока хватает кредитов и места в очереди (до 40).
* **Esc** — пауза и «Сдаться».
* В соло подсказки обучения появляются автоматически; их можно свернуть
  кнопкой «?».

## Деки

Перед матчем собираются **3 башни** и **3 юнита** (сохраняется в
`user://loadout.cfg`). В бою доступны только выбранные карты; количество
построек не ограничено.

| Башня | Роль | Юнит | Роль |
|---|---|---|---|
| Снайпер | бронебойный, бьёт тяжёлых | Бегун | дешёвый поток |
| Мортира | AoE по земле | Наездник | плотная конница |
| Криостан | замедление | Танк | аура −25 % урона союзникам |
| Огнемёт | дешёвый AoE в упор | Змей | воздух, иммунен к замедлению |
| Тесла | **только воздух**, цепь | Босс | 960 HP, 6 урона базе |

Полная матрица урона, экономика и обоснование чисел — в
[`docs/GDD_AUDIT_RU.md`](docs/GDD_AUDIT_RU.md), разделы 2.3.4 и H.7–H.9.

## Баланс-инструмент

`tools/balance_audit.py` — детерминированный симулятор (Python 3.10+, без
зависимостей). Повторяет `tower.gd` / `projectile.gd` / `game_state.gd`:
матрицу урона, приоритеты цели, ауру, сплеш, цепь, замедление, экономику.

```bash
python3 tools/balance_audit.py all          # профиль v3: геометрия, экономика, уровни,
                                            # сценарии боя, матрица дек, окупаемость прокачки
python3 tools/balance_audit.py decks        # только матрица «дека × состав атаки»
python3 tools/balance_audit.py levels       # прокачка юнита против массы за матч
python3 tools/balance_audit.py upgrades     # кривые 1..10 для башен и юнитов
python3 tools/balance_audit.py --profile v2 decks   # исторический снимок v2
```

Профиль `v3` (по умолчанию) — текущие числа из `scripts/game_db.gd` и
`autoload/game_state.gd`. После правки баланса **обязательно** прогнать
`decks`: матрица считает лучший ответ деки на каждый состав, поэтому ловит и
«одну кнопку», и деку без дыр.

## Известные ограничения

* Баланс проверен симулятором, **но не живыми матчами** (в окружении сборки
  не было Godot CLI). Чеклист плейтеста — приложение G аудита.
* Арт — примитивы (полигоны, процедурные текстуры): это прототип, не финал.
* Ранговый поиск требует Steamworks-приложения и заполненного Partner Portal.
